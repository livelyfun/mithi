My Projects

02

StockMatrix — real-time stock terminal

A full-stack trading dashboard covering NASDAQ, NYSE, NSE, BSE, LSE, Euronext, Tokyo and HKEX. A FastAPI backend issues OAuth2 / JWT auth, caches Yahoo Finance data in memory with TTL, and broadcasts price updates over per-user WebSocket connections. The React + TypeScript frontend renders SVG candlestick charts with OHLC crosshairs, evaluates price alerts in the background and fires browser toasts.

Stack: Python · FastAPI · SQLAlchemy · Alembic · WebSockets · Redis · Docker · React · TypeScript · Tailwind CSS

Kira Calculator — scientific desktop calculator

A cross-platform calculator where the interesting work is the math, not the chrome. I wrote the expression parser and evaluator to handle operator precedence, nested parentheses, powers, square roots, trigonometric functions, logarithms and the constants π and e, then covered it with an automated pytest suite. The PySide6 interface is split into calculator, converter and programmer pages with a custom QSS stylesheet.

Stack: Python · PySide6 · pytest · Qt Style Sheets

Source code ↗

AI Reel Studio — prompt to short-form video

An end-to-end automated video generator. One prompt drives a Gemini service that produces a storyboard, orchestrates visual asset generation, synthesises audio, aligns captions and assembles the pieces into a structured reel. It includes a storyboard viewer, generation progress view, reel player and per-platform metadata for Reels, Shorts and TikTok.

Stack: TypeScript · React · Vite · Express · Gemini AI · Web Audio API

YT Downloader — local Electron downloader

A desktop downloader that keeps everything on the machine. A React renderer drives an Electron main process that shells out to yt-dlp and ffmpeg, parsing their output for live progress, speed and ETA. It detects missing dependencies on launch, stores its config and download history under ~/.config, and ships as a standard .deb package with a .desktop entry.

Stack: JavaScript · Electron · React · Vite · Tailwind CSS · yt-dlp · ffmpeg

Source code ↗

Smart File Organizer — CLI that tidies Downloads

A small, dependable utility: install once, and everything that lands in Downloads gets filed into Images, Videos, PDFs, Documents, Archives, Code and more. It ships self-contained executables for Linux, macOS and Windows, and the install scripts verify the download against a published SHA-256 before running anything. The Python package is pytest-covered and built through pyproject.toml.

Stack: Python · pytest · pyproject.toml · Shell · PowerShell · Inno Setup

Source code ↗

MPM Services — Melbourne property website

A marketing site for a family-owned steam cleaning, strip & polish and property-maintenance business in Melbourne. Built as a dependency-light site on Vite with vanilla ES modules, a hash-based router and a custom CSS design-token system, so the client gets something fast and maintainable without a framework runtime to carry.

Stack: JavaScript · Vite · CSS Design Tokens · ES Modules
