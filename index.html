My Projects

02

Release Guardian — synthetic monitoring & release verification

A self-hosted, multi-tenant reliability platform that runs deterministic HTTP, real-browser and Lighthouse checks against production sites. It stores evidence, detects latency and regression changes, correlates failures with deployments, and manages incidents through to resolution. The control plane is FastAPI, the dashboard is Next.js, and Celery/Redis handle scheduling and browser workloads. Currently pre-1.0.

Stack: Python · FastAPI · Next.js · TypeScript · Playwright · Lighthouse · PostgreSQL · Redis · Celery · Docker

Stockpilot — inventory & stock control

An ASP.NET Core MVC inventory system for small and medium businesses. Purchases, sales, an immutable stock ledger, weighted-average valuation, concurrency-safe deductions, reversible transactions, role-based access, an append-only audit trail and CSV reports. Built on .NET 10, EF Core and PostgreSQL 17, with xUnit integration tests against a real database.

Stack: C# · .NET 10 · ASP.NET Core MVC · EF Core · PostgreSQL 17 · Bootstrap · xUnit · Docker

StockMatrix — multi-market real-time stock terminal

A full-stack trading dashboard covering NASDAQ, NYSE, NSE, BSE, LSE, Euronext, Tokyo and HKEX. FastAPI issues OAuth2/JWT auth, caches Yahoo Finance data with TTL, and streams per-user WebSocket updates. The React + TypeScript frontend renders SVG candlestick charts, evaluates price alerts, supports multi-currency conversion, i18n and dark/light themes.

Stack: Python · FastAPI · SQLAlchemy · Redis · WebSockets · Docker · React · TypeScript · Tailwind CSS
