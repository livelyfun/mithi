# Mithi — Personal Portfolio

Source code for my personal portfolio website, live at [mithesh.netlify.app](https://mithesh.netlify.app/). This repo also doubles as my git practice space, so history may include a fair number of learning commits.

## 🛠️ Tech Stack

- **Next.js** — React framework
- **Tailwind CSS** — styling
- **Framer Motion** — animations
- **GitHub Actions** — CI/CD (see `.github/workflows`)

## 📁 Structure

```
mithi/
├── .github/workflows/   # CI/CD pipeline
├── portfolio/           # Next.js portfolio app
└── .gitignore
```

## 🚀 Getting Started

Clone the repo and install dependencies inside the `portfolio` directory:

```bash
git clone https://github.com/livelyfun/mithi.git
cd mithi/portfolio
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000) to view it locally.
